七音音乐工作室 v1.4.0-public.1 · 音频识别到作曲的一体流程

一、先选正确的入口

桌面客户端包：先在 ZIP 上点右键 → 全部解压，再双击“七音音乐工作室.exe”。不要在压缩包内运行，也不要只复制一个 exe，必须保留旁边的 resources 等文件。无需自己安装 Node.js 或 Python。

数字作曲、音效实验室和内置高级作曲可以直接离线使用。要导入 MP3/WAV 自动分轨、识别音符，点击客户端顶部“准备音频识别”。它会在窗口内显示首次准备、下载与错误信息，不要求打开终端输入命令。
首次需要下载本机 Python、TensorFlow、Spleeter、Basic Pitch 和解码组件，合计约 1–2 GB。建议至少留出 6 GB 磁盘空间、8 GB 内存。分轨模型本身约 140 MB 下载、解压约 152 MB。实际空间随平台和下载缓存变化。
首次下载需要能访问官方 GitHub 和 PyPI。中国大陆网络可能访问不稳定；没有内置未经核验的镜像或在线代处理。下载失败会显示原因，不能离线首次完成安装。以后组件和模型齐全，可断网识别。

运行时保存在客户端的本机数据目录，不修改系统 PATH，不需要管理员，不会修改 PowerShell 执行策略。音频只交给本机回环服务。客户端会管理服务启停，不需要手动访问 localhost。

本文件夹也保留网页开发备用入口：index.html 可使用原有作曲功能；开发者可按 local_service/README.txt 自行准备本机服务。它们不是桌面客户端的主要入口。

二、推荐从 25 秒试听开始

1. 打开“音频识别”，选择完整混音 MP3/WAV，或已有的声部音频。
2. 首次先处理约 25 秒片段，避免等完整首歌后才发现不适合。
3. 混音模式用 Spleeter 估计人声、鼓、贝斯、其他四类声部。这些不是原录音工程中独立乐器轨的复原，可能串音或有分离失真。“其他”也可能包含多个乐器。
4. Basic Pitch 为有音高声部生成候选音符。鼓保留分离音频和节奏，不会假装成 1–7。
5. 用原声与音符试听对比，调整音高、起止时间、力度、音色、音量。自动调性、BPM 是待校正建议。模型分数不是百分比准确率。
6. 小片段满意后，再处理需要的较长内容。没有承诺实时速度或通用识别准确率。

三、编辑、保存与交接

识别工程以独立、带版本的 JSON 保存音符和分析信息。识别的绝对起止时间是基础数据；量化属于显式编辑，不会偷偷把所有音符吸到网格上。保存工程不等于把原始音频和分离音频一并封装，请另外导出需要的 WAV。

精确 MIDI 保留音符的独立起止时间。鼓原音和音效不能装进普通音高 MIDI；请另存 WAV。外部软件或高级作曲的 MIDI 导入可能限制轨道、精度、音色和节奏，因此不要把它当成无损工程格式。

已有的数字作曲器仍有 4 轨、180 拍、每音最短 0.125 拍、最多两个八度升降等限制。不能表示的片段必须缩小或明确量化后再尝试；导出识别工程/MIDI 保留原事件，不能默默丢音。请先保存已有数字作曲工程，再交接新的内容。

高级作曲使用随包完整 BeepBox 4.2.2，仍可离线编辑和保存原生 JSON。主要可见界面提供简体中文适配。识别结果通过明确的 MIDI 文件交接，不声称自动还原原曲全部效果。

四、隐私与运行范围

音乐仅发送到本机 127.0.0.1 服务，不上传第三方识别服务器、不需要账号或 API key。首次下载只是获取软件/模型，不会携带你的音频。服务拒绝远程地址、任意文件路径和外部网站跨域提交。输入被当作音频数据解码，不作为程序运行。

处理仅允许一个任务同时运行，可取消。错误或内存不足会如实停止，没有替代的假识别结果。服务临时文件的保存/清理以界面提示及本版测试报告为准；重要音频请自行备份。

五、常见问题

- 双击 index.html 后识别不可用：请打开桌面客户端，并点“准备音频识别”；原有作曲在网页备用入口仍可继续。
- 窗口显示下载失败：检查网络和磁盘空间，再使用客户端的重试按钮。不要绕过 Windows 安全提示，不要关闭杀毒软件。
- 提示缺少 Visual C++ DLL：TensorFlow 在部分电脑需要微软运行库。请仅从微软官方说明获取支持的 x64 运行库：https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist 。安装需要你自行确认。
- 客户端打不开：确认 Windows x64、已完整解压。当前制作环境没有实测 Windows，可能还存在系统相关兼容问题。源码备用启动方式与客户端不同。
- 备用服务提示端口已占用：先关闭之前的七音启动窗口，不要随意结束不认识的进程。桌面客户端自行选择本机端口。
- 修改运行时目录或移动便携客户端后，如组件检查失败，请保留工程并按照窗口提示重新准备，不要直接删除唯一的音乐工程备份。
- 识别不准：换较清晰的声部或较短片段，逐音校对；复杂混音、长混响、多乐器“其他”轨并不保证还原。
