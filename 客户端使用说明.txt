七音音乐工作室 1.4.0-public.1 · Windows x64 公开基础版

1. 全部解压 ZIP，双击“七音音乐工作室.exe”，保留 resources 等全部文件。
2. 数字作曲、音效与 BeepBox 高级编辑器使用本地资源，无需账号或 API Key。
3. 自动分轨、音符识别、图片五线谱识别需要另外准备组件，不是基础版内置即用功能。
4. 音频识别在顶部“准备音频识别”经确认后从官方来源联网下载。本公开包不含预装 Python、TensorFlow、模型、FFmpeg 或 VC++ 安装器。
5. 五线谱识别请先自行安装官方 Audiveris，再在“配置五线谱识别”选择其 EXE；不要选择不明程序。官方来源：https://github.com/Audiveris/audiveris/releases 。安装过程中的许可与系统权限由你确认。
6. 未在真实 Windows、声卡或系统保存窗口验收；不保证你的系统上已能运行所有可选组件。不要绕过系统安全提示。
7. 当前公开基础 ZIP 是完整客户端；历史“完整离线组件更新”是增量包，须配合指定旧客户端，并非本次公开下载。
8. 更新前导出工程 JSON 和重要 WAV/MIDI。先把新版解压到新目录，不要覆盖唯一的工程或运行库备份。

功能、版本、开发和已知限制以 README.md、docs/BUILD.md、docs/VALIDATION.md 为准。
