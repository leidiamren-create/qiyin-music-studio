七音 · 音乐与音效工作室 1.4.0-public.1
============================

桌面客户端入口（Windows x64）
1. 先全部解压 Windows 客户端 ZIP，保留全部文件。
2. 双击“七音音乐工作室.exe”。作曲和高级编辑器可直接离线使用。
3. 自动分轨/识别请点窗口顶部“准备音频识别”，首次需要网络下载本机组件。
4. 不需要在终端输入命令，也不需要自己安装开发工具。

网页备用入口（仅作为兼容/开发备用）
1. 在下载的 ZIP 上点右键 → 全部解压。
2. 进入解压后的文件夹，双击 index.html。
3. 推荐使用桌面版 Microsoft Edge 或 Google Chrome。
4. 点“播放旋律”即可试听。需要你主动点播放，浏览器才会允许发声。
这些原有作曲功能无需安装 Node.js / Python / 开发工具，不需要账号或 API Key。自动分轨与识别需要首次下载本机组件，详见“音频识别使用说明.txt”。
不要只从压缩包里拖出 index.html：其余文件和 vendor 文件夹也必须保留。

作曲
- 1 2 3 4 5 6 7 对应 do re mi fa sol la ti；0 是休止。
- 单个数字默认持续一拍，123 与 1 2 3 相同。
- 1' 高一个八度；1, 低一个八度。最多升降两个八度。
- 1:2 持续两拍；1/2 持续半拍；1:0.25 持续四分之一拍。
- 1. 是附点，持续1.5拍；1/2. 持续0.75拍。
- [135]:2 同时弹1、3、5，持续两拍。
- #4 升半音；b7 降半音。
- | 是视觉小节分隔，不会自动补齐一小节。
- 不想记语法：选八度、时值，直接点数字键或和弦按钮。
- 时间线点选一个音符，可修改或删除；数字键替换乐谱中选中的文字。
- 最多4条音轨，同时从第1拍开始。前面加0可延迟进入。
- 速度40–240 BPM，每轨最多180拍，每次导出最多90秒。
- 鼓组：1底鼓、2踩镲、3军鼓、4嗵鼓、5开镲、6镲、7拍手。

高级作曲（1.1 新增）
“03 高级作曲” → “打开高级作曲”：进入随包的完整 BeepBox 4.2.2。
在同一标签页打开本地文件，不是联网网站。主页面声音会停止。
无需安装和编译，保留原有数字作曲与音效。
高级编辑器已有简体中文显示适配，内部文件格式和标准缩写保留原样。

1. 上方格子点音符，拖动改长度；同一时刻不同音高可组成和弦。
2. 下方彩色数字格是 Pattern（片段），可重复编排，多条音轨可同时播放。
3. 空格播放/暂停。Tempo 是速度、Key 是调性、Scale 是音阶、Instrument 是乐器。
4. File → Import Song 导入；File → Export Song 导出；Edit 调整歌曲与片段；Preferences 调整界面和操作习惯。
5. 点击顶部“保存高级工程 JSON”保留全部歌曲、原生音色参数和曲线。
   或 File → Export Song → JSON；保留 Intro、Outro，Loop Count 选 1，以保留完整原结构。
6. 高级 JSON 在高级页导入；简谱 JSON 在七音主页打开。两种工程格式不能混用。
7. 返回前先保存 JSON。浏览器禁止存储时会提示，仅内存保存不能跨关闭保留。

简谱 → 高级作曲
先在主页面“高级作曲”页点“导出当前简谱 MIDI”；打开高级编辑器，File → Import Song，选择下载的 .mid。
这是单向的近似音符交接，不是无损转换；音色、鼓组、复杂节奏、和弦和曲线可能改变，务必试听。
静音音轨不导出；真实乐器录音采样、jsfxr 音效不随 MIDI 搬入高级编辑器。
导入 MIDI 会先提示保存当前高级歌曲，因为随后会替换它。
不自动把高级歌曲转换回受限简谱，以免丢掉片段、合成器参数和音符曲线。

高级编辑器离线功能与边界
- 完整原生音符/片段/多轨编辑、合成器音色、效果、播放、JSON/MIDI 导入与 WAV/MIDI/JSON 导出。
- 不受简谱区 4 轨和 90 秒上限约束，仍有 BeepBox 自身的通道、片段、歌曲长度上限。
- WAV 为原生 BeepBox 输出，与简谱区独立音源不同。MIDI 接收软件会重新决定音色。
- 本包移除了需要外部编码器的 MP3 选项。可先导出 WAV，用自己的音频软件转换。
- Copy Song URL 复制的是带歌曲数据的本地链接。它只在软件路径正确的设备有效；发给别人或换电脑请传 JSON 和软件包。
- Export HTML 是指向当前本地编辑器与歌曲的跳转文件，不是独立的声音文件或整套软件。
- 内置本地迷你播放器，供 View in Song Player 和 Recover Recent Song 使用；恢复依赖浏览器本地存储。
- 外部链接仍可在点击时联网；联网字体、在线短链接、MP3 下载和服务工作线程已停用。
- 单次导入文件上限 2 MB，歌曲 URL 上限 200 KB。只打开你信任的音乐工程；格式检查不等于完整安全沙箱。
- 主要界面已有中文显示适配，内部标识、标准缩写和部分调试信息仍为英文。推荐桌面 Edge / Chrome。
- 自动化已覆盖 DOM 与真实合成 PCM，但本环境未完成真实浏览器渲染、硬件试听、Windows 双击文件及系统下载对话框实测。

音效
“音效实验室”提供金币、跳跃、激光、爆炸、打击、挥动预设。
可以调整起止音高、长度、渐入、衰减、噪声、低通滤波、波形、音量和随机种子。
相同的参数和种子生成相同声音。音效独立试听/导出，不会自动混入歌曲。

保存和导出
- 主页面“保存工程”：下载简谱 JSON，包含数字作曲音轨、音色、音量、速度、调性、循环和音效参数；不包含独立高级歌曲。
- 打开工程：选择已保存的 JSON。打开后可通过撤销回到之前工程。
- 自动保存：仅当前浏览器允许本地存储时可用，不代替主动备份。
- WAV：44.1kHz、16位、单声道PCM，可导入常见游戏引擎和视频剪辑软件。
- MIDI：标准MIDI格式1；保留节拍、音高、和弦及对应GM乐器/鼓组。实际音色取决于接收软件。
- 导出文件会在浏览器设置的下载位置出现，未自动弹出保存对话框不代表导出失败。
- 播放和WAV使用同一PCM；音乐末尾保留短余音。循环按乐谱拍数回到开头，不额外等待尾音。

撤销与编辑
撤销/重做最多保留100次工程编辑。
Ctrl+S 保存；不在文本框时 Ctrl+Z 撤销，Ctrl+Shift+Z 或 Ctrl+Y 重做。
正在输入文字时使用浏览器原生文本撤销。
编辑乐谱、音色或音量会停止当前播放，修改后再点播放。

隐私
普通作曲使用本地资源，不会把工程上传到识别服务器。可选识别组件首次准备会联网下载；依赖隐私边界见 local_service/README.txt。程序只处理你选择的输入及其本地工作数据。
只在你选择导入时读取所选 JSON / MIDI，并在浏览器允许时写入该网页的本地存储。高级页外部作者和说明链接只有点击时才会离开本地页面；在线短链接及系统分享入口已移除。
不要把其他来源的HTML/JS文件混入本文件夹。

范围与已知限制
- 数字作曲区适合短配乐；新增高级作曲是完整 BeepBox 编辑器，仍不是录音混音型专业 DAW。
- 不支持录音、麦克风、外部 VST 插件或歌词演唱。简谱区无实时 MIDI；高级编辑器保留原生 MIDI 输入选项，其使用取决于浏览器支持、设备和你授予的权限，未在本环境验证。
- 提供的乐器不代表世界上所有乐器；采样与合成音色会在下拉框中明确标记。
- 小型采样集依靠变调覆盖音域，极端高低音可能不如大型音源自然。
- 90秒上限包含导出余音，接近上限时请少写一两个音或略提高BPM。
- 页面程序、数据和DOM模拟已做自动化检查；未声称已在你的Windows电脑或真实浏览器中实机试听。
- 遇到没声音时检查主音量、轨道静音、系统音量和输出设备；刷新后重新点击播放。

v1.2 新增：选中音轨的音色雕刻
- 在“数字作曲”选中一条音轨，开启“音色雕刻”。
- 起始/结束音高是相对谱面音符的半音偏移，每个 1–7 音符仍保持自己的音高关系；不是把整首歌固定成同一个 Hz。
- 发声占音长比例只调每个音的发声长度，不改拍子、时间线或休止符。
- 渐入、衰减、噪声、低通和效果音量会真正作用于采样音色和合成音色的试听及 WAV。
- 没有种子控件；内部仍保持重复渲染一致。
- 新设置会随简谱 JSON 保存。旧 v1 文件照常打开，新效果默认关闭。
- MIDI 只保留音符/节拍，不携带这些声音处理；要保留听到的效果请导出 WAV。

v1.2 新增：音频识别
- 导入混音或已有分轨，先做约 25 秒测试，再决定是否处理完整剩余片段。
- 四声部为模型估计，不是原工程乐器轨复原；候选音符可能误报、漏报，需要人工试听校对。
- 可精确编辑音高、起止秒数和力度，换音色、加入音效，再导出 MIDI / WAV。
- 识别 JSON 与原有简谱 JSON、BeepBox 高级 JSON 是明确区分的工程格式，不能互相直接冒充。
- 识别到简谱通过显式确认交接，不能表示的节奏/复音将提示限制；完整事件仍可保存在识别工程与 MIDI。
- 首次下载、隐私、实际测试结果及 Windows 未实测边界见“音频识别使用说明.txt”docs/VALIDATION.md。
