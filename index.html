检查本地识别服务

数字作曲与音效实验室仍可直接离线使用。音频识别需要本地组件，首次安装会下载模型。

本地安装说明
  1. 先完整解压文件夹。数字作曲与音效实验室可直接打开 index.html 使用。
  2. Windows 音频识别：双击“启动七音-含音频识别.cmd”。首次需要联网下载约 1–2 GB 组件与模型，建议至少 6 GB 可用空间、8 GB 内存。
  3. 保持启动窗口打开，在自动打开的本地页面导入音频。以后模型留在本机，音频不上传云端。
  4. 若下载失败，请检查网络与启动窗口的提示；其他系统请阅读随包“音频识别使用说明.txt”。不要只复制单个页面。

数字怎么写？

1=do、2=re、3=mi、4=fa、5=sol、6=la、7=ti，0 是休止。默认每个数字 1 拍。123 和 1 2 3 都可以。

1' 高八度，1, 低八度；1:2 持续 2 拍；1/2 持续半拍；1. 是附点 1½ 拍；[135]:2 是持续 2 拍的和弦；#4 升半音，b7 降半音。竖线 | 仅分组，不改变节拍。

两种工程，各自完整保存

上方“保存工程”只保存数字作曲与音效。高级歌曲请在高级编辑器中保存 JSON；它保留原生片段、乐器和音符曲线，不转成受限简谱。两个 JSON 格式不能混用。

高级编辑器在同一标签页打开，进入时会停止此页声音。返回前请保存高级工程；移动文件夹或换电脑时传 JSON 备份。高级区不受简谱区的四轨、90 秒限制。

WAV、MIDI、JSON 可离线导出；此离线包不提供 MP3 编码。无需联网或账号。

从 0 到第一段音乐

  1. 选择一个音色，用下方数字键输入旋律，或直接输入 1 2 3 5。
  2. 设置速度和调性。点“播放旋律”，时间线会高亮正在播放的音符。
  3. 增加音轨可以加入和弦或低音。各轨同时开始，用 0 添加空拍。
  4. 导出 WAV 得到可用于游戏或视频的声音文件；MIDI 保留音高和节拍，方便后期换音色。
  5. “保存工程”下载简谱 JSON，完整保存数字作曲的轨道、乐谱和音效参数。高级作曲使用独立 JSON。下次“打开工程”继续编辑。

音频识别新增工作流

先在“音频识别”查看本地安装说明。首次运行需要下载识别组件与模型，之后音频在本机处理。建议先试 25 秒：分轨 → 识别 → 听音校正 → 换音色 / 加音效 → 导出。识别工程 JSON 与原来的简谱工程、BeepBox 高级工程是三种不同格式，不能混用。

重要提醒

  • 请先解压整个文件夹，再双击 index.html。推荐桌面版 Edge 或 Chrome。无需安装开发工具。
  • 本页不上传乐谱或音频。浏览器若允许，会在本机自动保留最近工程；正式备份请点“保存工程”。
  • 导出文件位置由浏览器下载设置决定。WAV 是 44.1 kHz、16 位、单声道 PCM。
  • 播放与 WAV 使用同一 PCM 引擎。MIDI 音色由接收软件决定，可能与此处不同。
  • 曲目上限为 4 轨、每轨 180 拍、总长度 90 秒。适合短配乐和游戏音效。
  • 未按下播放前浏览器不会出声。如无声，请检查主音量、音轨静音和系统输出设备。

快捷键

Ctrl+S 保存工程；Ctrl+Z 撤销；Ctrl+Shift+Z / Ctrl+Y 重做。正在输入文字时保留浏览器原生文字撤销。
